## 使用

下载发行包，把 ZIP 内全部文件解压到游戏的 `mods/RouteSuggestPlus/` 目录，在模组列表启用。保留 `.dll`、`.pck` 和 `.json`，其中 `.pck` 提供游戏内封面。**请停用原版 RouteSuggest**，两者会给同一批地图虚线上色。首次启动时如果找到原版的 `RouteSuggestConfig.json`，会自动导入其中的路线和权重。

打开地图即可看到路线：

- **金色流光**：精修推荐。按当前血量、金币、删卡价格、药水、层数和近期战力，沿每条候选路线逐个节点模拟后选出。
- **其他颜色**：原版的固定权重路线（默认 Safe 淡蓝、Aggressive 红），以及你导入的自定义路线。原来用金色的路线会自动改成淡蓝，避免和精修路线撞色。
- 多条路线走同一段时**左右对称并排**，不互相覆盖；到节点处收拢。
- **右键未来节点**可固定/取消固定（节点被一圈手绘红墨圈住，左下角贴着当前角色的小头像），所有路线都只从经过固定节点的路径中选择；固定节点之间无法同时到达时，地图上方会提示，并且只显示固定节点、不画路线，取消其中一个即可恢复。走到别的分支后已无法到达的固定节点会自动取消。换层时自动清空。在节点以外右键仍是原生画笔。
- **F7** 或地图右下角「◆ 路线设置」打开设置面板，Esc 关闭。按住这个按钮可以拖到别处；按住面板标题栏可以拖动面板，位置都会记住。

## 精修推荐怎么算

每条路线从当前状态出发逐节点推演（期望值），各模块都可以在设置面板里单独开关：

| 模块 | 规则 |
|---|---|
| 商店看金币 | 商店价值 = 金币曲线 × 删卡折扣。到店金币 100 以下为 0，300 满收益，中间线性；删卡价 75 时不打折，越贵折得越多，175 及以上打 7 折。出店按消费 325 扣除金币，连续两个商店后一个基本无价值。 |
| 药水换精英 | 普通药 0.5、罕见/稀有/事件药（含龙涎香、发光水）1.0；每只精英最多消耗 1.0，抵扣部分掉血并加分。路上掉药从游戏**实时掉药概率**出发，按（持有药水数, 当前掉率）的概率分布逐场推演（含 ±10% 保底机制、精英 +12.5%），药水栏满时掉的药不计。 |
| 分层精英 | 精英收益 第一层 ×1.3、第二层 ×1.0、第三层 ×0.8。 |
| 血量安全线 | 每场预计掉血（小怪 9/13/13、精英 25/28/23）取自 240 局单人 A10 胜利记录的 p85；1/2/3 层绝对血量 10/20/30 为软安全线，进 Boss 前 20/25/40，低于时按平方扣分，整体权重较低。火堆一律按睡觉（游戏实际回血量）估算，不再分支。 |
| 近期战力 | 从本局地图历史读取最近 3 场普通/精英战斗（读档后仍有效），「实际受伤 ÷ 该类战斗预计掉血」按 0.5/0.3/0.2 加权（最后一场最重），向 1 收缩后修正后续预计掉血，范围 0.7–1.4。 |

**飞鞋（Winged Boots，3 次飞到下一行任意房间）**：持有且有剩余次数时，精修路线允许飞行，飞行段画成金色虚线弧，会自动绕开沿途其他房间（必要时绕个弯），不会压在房间上被误看或误点。本层内用（房间, 已飞次数）上的束搜索规划，每格只留几个最优状态；跨层用离线统计的「保留价值」决定本层飞几次、留几次：本层飞 j 次的收益 + 后续各层持有剩余次数的期望收益，取最大。保留价值来自用游戏自带地图生成器生成的 1200 张图（第一层 600、第二/三层各 300）。每次飞行计 1.5 分代价，收益不明显就不飞；扣掉代价后每层第 1 次飞行平均约 +4 分，第 2 次约 +1.5，第 3 次约 +0.8。3 次在手时最优策略多为第一层飞 1 次，视当层地图上下浮动。打开地图时顶栏中间有一个飞鞋小条（飞鞋图标 + 剩余次数 + 自动 / 0 / 1 / 2 / 3），选本层一共飞几次：手动选几次就恰好飞几次（不再扣飞行代价，地图上飞不出那么多次时按最多能飞的算），已飞的自动计入，超出可用次数的选项不可选，换层后回到自动。小条可按住拖动，右键回到默认位置；设置面板的「恢复默认位置」会把按钮、面板、小条一起复位。研究程序见 `tests/FlightStudy.cs`。固定节点在有飞行次数时即使走不到也会保留（可以飞过去）。

**火堆遗物**：有迷你帐篷（MiniatureTent，火堆可做多个选项）时，每个火堆 +2（睡觉和敲牌都能做），每多一个火堆相关遗物再 +1（南瓜蜡烛、Girya、切肉刀、Pael 的成长、铲子、捕梦网、皇家枕头、石质加湿器、迷你信箱、永恒羽毛）。例：帐篷 + 南瓜蜡烛 → 火堆 4 + 2 + 1 = 7。没有帐篷时这些遗物默认不加分（可在配置里调 `rest_relic_bonus_no_tent`）。

问号节点按游戏当前的未知房概率（怪 / 宝箱 / 商店 / 事件），按概率把各结果的期望效果叠加到同一个状态上（不分支）；与游戏规则一致：上一个房间是商店（含问号开出的商店）或下一层全是商店时，问号不会出商店，且此时商店概率不增长。读数会显示在设置面板的「当前评估」里，方便核对。

更多参数（各项权重、掉血、安全线、药水价值、单个药水覆盖等）在模组目录的 `RouteSuggestPlusConfig.json`，改完重开游戏生效，填错的项会自动回退为默认值并在面板提示；面板里的开关与滑条即时生效并自动保存。

## 构建与验证

本机基线：尖塔 2 `v0.111.0 / 41cef1ea`。需要 Windows、PowerShell 7 和本机游戏文件（不随仓库分发）。在本仓库根目录执行：

```powershell
pwsh -NoProfile -File scripts/build.ps1          # 加 -Install 安装，覆盖前备份到 artifacts/routesuggest/
pwsh -NoProfile -File tests/run-planner-tests.ps1
```

默认游戏目录为 `C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2`，可用 `-GameDir` 指定其他位置。构建输出位于 `dist/RouteSuggestPlus/`，压缩包位于 `dist/`。

原生集成测试另依赖本仓库之外的 `research/animated_cards/run_game_probe.py` 及其配套资源，未打包为独立测试环境。已有该工具项目时可运行 `pwsh -NoProfile -NonInteractive -File tests/test-native.ps1 -ToolProject <工具项目目录> -Python <Python可执行文件>`。2026-10-22 发布前已重新通过 43 项离线测试、45 项原生检查和封面资源加载校验；发行 DLL 与原生测试 DLL 哈希一致。

- 离线测试 43 项：商店/删卡公式、药水抵精英与药水栏（精确概率树）、分层、血量安全线、火堆回血、战力加权与收缩、问号期望叠加、商店后不出商店（含连续问号）、问号概率按游戏顺序分配、药水价值守恒、配置修复、飞鞋规划（飞行可达、不需要时不飞、手动选几次就飞几次、固定节点、跨层保留）、火堆遗物加成、模块全关退化为原始权重。
- 原生测试：使用独立运行目录、独立用户目录、关闭 Steam，不读写个人存档。覆盖实时状态读取、精修路线与流光、多线并排、真实地图输入路径的右键固定、剪枝枚举与冲突提示（冲突时不画路线）、设置开关、金币变化、行进时撤下覆盖层且不覆盖游戏的已走颜色、真实战斗后从地图历史读到的战力样本、面板释放后的生命周期、面板拖动、手绘固定圈与头像、飞鞋次数读取与飞行弧、顶栏飞鞋小条（手动 0/1/3 次、拖动、右键复位）、提示自动淡出。测试 DLL 不随包发布。
